COMO ADICIONAR UMA CIFRA
------------------------
Caminho principal: o FAVORITO. O Cifra Club bloqueia os servidores do GitHub (403), entao
quem le a pagina e o seu proprio navegador:
  1. No app, abra "Configurar o favorito (uma vez por aparelho)" e toque em "Copiar codigo".
  2. Crie um favorito chamado "Cifras" cujo endereco e esse codigo (as instrucoes por
     aparelho estao na propria tela: Android, iPhone e PC).
  3. Na pagina de uma cifra no Cifra Club, acione o favorito (no Android: digite "Cifras"
     na barra de endereco e toque nele). O app abre com a cifra ja guardada, acordes no lugar.
Caminho secundario: "Ou cole o link" dispara uma GitHub Action que tenta buscar a pagina.
Hoje ela e barrada pelo Cifra Club; fica como tentativa, e o app avisa se falhar.

TOKEN E PIN (uma vez por aparelho)
----------------------------------
Para GRAVAR (adicionar, mudar tom, riffs, apagar) o app precisa de um token do GitHub:
  github.com -> Settings (perfil) -> Developer settings -> Personal access tokens
  -> Fine-grained tokens -> Generate new token.
     Repository access: Only select repositories -> "cifras"
     Permissions -> Repository permissions -> Contents: Read and write
     Expiration: 90 dias ou 1 ano (quando vencer, o app avisa e pede outro).
No app, toque na chave (🔑), cole o token e crie um PIN (minimo 6 caracteres). O token fica
CIFRADO no aparelho com esse PIN; o PIN e pedido uma vez a cada abertura, na primeira
gravacao. Sem token o app so le. Sem internet, abre a copia local.

RIFFS: QUE NOTAS A MUSICA ESTA TOCANDO
--------------------------------------
Em cada riff (trecho do video, ex.: 1:48 a 1:54) ha tres jeitos de o app DETECTAR as notas:
  🎤 microfone        celular: o app toca o trecho no video e ouve pelo microfone. Volume
                      alto, sem fone, aparelho perto do alto-falante (ou de outro aparelho
                      tocando a musica).
  🖥 audio da guia     PC (Chrome/Edge): escolha ESTA guia na janela e marque "Compartilhar
                      audio da guia". Som limpo, melhor resultado.
  📁 arquivo de audio  o arquivo da musica (mp3/m4a/wav): o app analisa so o trecho do riff.
                      Mais preciso de todos; o tempo do arquivo precisa bater com o do video.
O resultado mostra as notas presentes no trecho (com oitava), o acorde provavel e a
sequencia de nota mais forte por instante (ex.: E5(0.5s) G#5(0.5s) B5(0.5s)), desenhadas
no piano. Fica salvo no riff. E uma leitura por espectro, nao um ouvido humano: funciona
bem para linha de teclado/guitarra e acordes simples; em trecho cheio (bateria, voz, baixo
junto) ele lista as notas dominantes. Use como ponto de partida e confira no instrumento.
O YouTube nao entrega o audio ao site (o player e de outra origem), por isso a captacao e
pelo aparelho.
Apagar um riff: botao 🗑 no proprio cartao.

SEGURANCA (o que esta feito e por que)
--------------------------------------
  - Fora dos buscadores: meta robots (noindex, nofollow, noarchive, noimageindex,
    nosnippet) e docs/robots.txt. Limite: o GitHub Pages nao manda cabecalho X-Robots-Tag
    e o robots.txt so vale na raiz do usuario (outro repositorio); a meta e o que segura.
    O REPOSITORIO e publico e aparece na busca do GitHub (so plano pago evita).
  - Content-Security-Policy na <meta>: script so o proprio (hash SHA-256, sem
    'unsafe-inline') e o player do YouTube; conexoes so ao site e a api.github.com;
    frames so do YouTube; nada de objetos, formularios ou <base>.
    ATENCAO: mudou uma letra do script de docs/index.html? Rode "node scripts/csp.mjs"
    antes de subir, senao a pagina abre em branco. O script ja normaliza CRLF -> LF.
  - Token: fine-grained, um repositorio, Contents apenas, com validade. No aparelho fica
    cifrado (AES-GCM, chave por PBKDF2 com 310 mil voltas a partir do PIN) e so existe
    aberto na memoria da aba. Motivo: todos os sites *.github.io do mesmo usuario dividem a
    mesma origem (o site do casamento le o mesmo localStorage). Pior caso se vazar:
    alguem edita cifras.
  - Tudo que vem do Cifra Club, do favorito ou do JSON e escapado antes de ir para a tela
    (testado com <script> dentro da letra: vira texto).
  - YouTube em modo privacidade (youtube-nocookie.com).
  - Action: permissao so "contents: write", actions travadas por hash de commit, uma
    execucao por vez, dispara so quem tem o token.
  - Sem segredo em arquivo nenhum desta pasta.

PUBLICAR MUDANCAS
-----------------
A pasta e um repositorio git ligado ao GitHub (gh ja autorizado nesta maquina):
  node scripts/csp.mjs   (se mexeu no index.html)
  git add -A ; git commit -m "..." ; git push
O Pages republica sozinho em 1 a 2 min.
