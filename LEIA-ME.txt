MINHAS CIFRAS - VERSAO GITHUB PAGES
===================================
Tudo nesta pasta vai para um repositorio do GitHub. O site sai de docs/ pelo GitHub Pages,
a biblioteca e o arquivo docs/dados/biblioteca.json e a busca no Cifra Club e feita por
uma GitHub Action (o navegador nao consegue ler o Cifra Club direto).

Ja vem com o "Poderoso Nome" dentro.

PASSO A PASSO (uma vez so)
--------------------------
1. Crie o repositorio: github.com -> New repository -> nome "cifras", Public, sem README.
   (Pages em repositorio privado exige plano pago; cifra nao e segredo, e o token NAO
   fica no repositorio.)

2. Suba os arquivos: no repositorio vazio, "uploading an existing file" -> arraste o
   CONTEUDO desta pasta (as pastas .github, docs e scripts, e este LEIA-ME). Commit.
   Se o navegador nao deixar arrastar a pasta oculta .github, crie o arquivo pela
   interface: Add file -> Create new file -> nome ".github/workflows/buscar-cifra.yml"
   e cole o conteudo do arquivo de mesmo nome daqui.
   Confira que docs/.nojekyll e docs/robots.txt subiram (arquivos pequenos, faceis de
   ficar para tras).

3. Ligue o Pages: Settings -> Pages -> Source "Deploy from a branch" -> Branch "main",
   pasta "/docs" -> Save. Em 1 a 2 min o site esta em
      https://SEU-USUARIO.github.io/cifras/

4. Libere a Action para gravar: Settings -> Actions -> General -> Workflow permissions
   -> "Read and write permissions" -> Save.

5. Crie o token que o app usa para gravar (no celular e no PC):
   github.com -> Settings (do seu perfil) -> Developer settings -> Personal access tokens
   -> Fine-grained tokens -> Generate new token.
      Repository access: Only select repositories -> "cifras"
      Permissions -> Repository permissions -> Contents: Read and write
      Expiration: 90 dias ou 1 ano (quando vencer, o app avisa e pede outro).
   Copie o token. No app, toque na chave (🔑) no topo, cole o token e crie um PIN
   (minimo 6 caracteres). O token fica CIFRADO no aparelho com esse PIN, e o PIN e pedido
   uma vez a cada abertura do app, na primeira gravacao.

6. Instale no celular: abra o endereco no Chrome -> menu ⋮ -> "Adicionar a tela inicial".

COMO FUNCIONA DEPOIS
--------------------
  - Colar link do Cifra Club -> o app dispara a Action -> em 30 s a 2 min a cifra aparece.
    Da para acompanhar na aba Actions do repositorio. Erros (link errado, 404) aparecem
    no proprio app.
  - Mudar tom, simplificar, salvar riff, apagar -> o app grava o JSON direto no
    repositorio (um commit por mudanca, juntadas em 1,5 s). Se dois aparelhos gravarem
    ao mesmo tempo, o app rele, mescla e reenvia sozinho.
  - Sem o token, o app so le (e guarda as mudancas apenas no aparelho).
  - Sem internet, abre a copia local.

SEGURANCA (o que esta feito e por que)
--------------------------------------
  - Fora dos buscadores: <meta name="robots" content="noindex, nofollow, noarchive,
    noimageindex, nosnippet"> em cada pagina e docs/robots.txt (Disallow: /).
    Limite honesto: o GitHub Pages nao deixa mandar cabecalho X-Robots-Tag, e o
    robots.txt so vale de verdade na raiz do usuario (SEU-USUARIO.github.io/robots.txt),
    que pertence a outro repositorio; a meta e o que segura. O REPOSITORIO em si e
    publico e aparece na busca do GitHub, isso nao tem como evitar sem plano pago.
  - Content-Security-Policy na <meta>: script so o proprio (por hash SHA-256, sem
    'unsafe-inline') mais o player do YouTube; conexoes so ao proprio site e a
    api.github.com; frames so do YouTube; nada de objetos, formularios ou <base>.
    ATENCAO: mudou uma letra do script de docs/index.html? Rode "node scripts/csp.mjs"
    antes de subir, senao a pagina abre em branco.
  - Token do GitHub: fine-grained, um repositorio so, Contents apenas, com validade.
    No aparelho fica cifrado (AES-GCM, chave derivada do PIN por PBKDF2 com 310 mil
    voltas) e so existe aberto na memoria da aba. Motivo: todos os sites *.github.io do
    mesmo usuario dividem a mesma origem (o site do casamento le o mesmo localStorage);
    o PIN e o que separa. Pior caso se vazar: alguem edita cifras. Nada alem disso.
  - Tudo que vem do Cifra Club ou do JSON e escapado antes de ir para a tela (testado
    com <script> dentro da letra: aparece como texto).
  - YouTube em modo privacidade (youtube-nocookie.com).
  - Action: permissao so "contents: write", versoes das actions travadas por hash de
    commit (nao por tag), uma execucao por vez, dispara so quem tem o token.
  - Sem segredo em arquivo nenhum desta pasta.

SE A ACTION FALHAR COM 403
--------------------------
O Cifra Club barra alguns clientes. O script tenta primeiro o fetch do Node e, se for
barrado, abre um Chrome de verdade (Playwright) dentro da Action — demora mais (uns 2 min),
mas passa. Veja o log na aba Actions.

ARQUIVOS
--------

  docs/manifest.json, sw.js, icone-*.png   instalacao como app e uso sem internet

  .github/workflows/buscar-cifra.yml   a Action
